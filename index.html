APIs, horarios y preferencias del sistema
🔑 APIs requeridas
El sistema necesita ambas APIs para funcionar automáticamente. Sin ellas, el botón "Generar" no funcionará.
⚠️ Importante — CORS: Las APIs de OpenAI y Anthropic bloquean llamadas directas desde el navegador por seguridad. Para que funcione sin servidor necesitas una extensión de Chrome que permita CORS, o contacta a tu desarrollador para montar un proxy simple. Otra opción: instala la app en un servidor web propio.
OpenAI API Key REQUERIDA — Imágenes gpt-image-2
Obtén en platform.openai.com → API Keys. Usa gpt-image-2 → gpt-image-1.5 → gpt-image-1 automáticamente.
Anthropic API Key REQUERIDA — Textos Claude
Obtén en console.anthropic.com → API Keys. Costo ~$0.003 por texto.
Google Drive API Opcional — Sincronización
Para guardar en la nube y compartir entre computadores.
